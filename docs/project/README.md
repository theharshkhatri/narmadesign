## Status vocabulary

- **Locked**: agreed direction that should not be changed casually.
- **Illustrative**: an example to validate or replace; not approved final content.
- **Open**: an input or decision still required before release.
- **Verified**: demonstrated by implementation or a recorded QA check. A target is not verified merely because it is written here.

When a request conflicts with a locked decision, stop and ask for an explicit revision. When this specification conflicts with an implementation detail, preserve the product requirement and document the technical adaptation.

## Prototype boundary

The first prototype proves the visual identity, layout system, and core interactions. It is not a claim that the contact backend, deployment, security controls, or production operations are complete.
